# SoloDefStudio — Certificate Generator

Android-приложение для массового создания персональных PDF-сертификатов и дипломов из CSV.

## Возможности
- Коллекция художественных оформлений с премиальной золотой палитрой.
- Выбор макета с предпросмотром.
- Импорт пользовательских JPG, PNG и PDF-шаблонов.
- Перемещение и сохранение полей заполнения на пользовательском макете.
- Генерация отдельных PDF и общего ZIP-архива.
- Выбор папки сохранения через системный файловый диалог.
- Проверка обновлений и загрузка APK из GitHub Releases.

## Использование
1. Подготовьте CSV-файл с колонкой «ФИО», «name», «full_name» или «participant».
2. Выберите оформление или добавьте собственный шаблон.
3. Загрузите CSV со списком участников.
4. Заполните название мероприятия и дату.
5. Выберите папку сохранения (необязательно) и нажмите «Создать сертификаты».

## Сборка
GitHub Actions → Android APK and Release.
Debug APK публикуется как workflow artifact. Релизный APK собирается и подписывается постоянным ключом проекта при коммите с маркером `[release]`.
Версия и тег релиза берутся автоматически из `app/build.gradle`.
