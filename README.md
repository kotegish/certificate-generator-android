# Генератор сертификатов Android

Приложение для массового создания персональных PDF-сертификатов из CSV.

## Как использовать
1. Подготовьте CSV-файл с колонкой «ФИО» (или name), по одному участнику в строке.
2. Откройте приложение и выберите CSV.
3. Заполните название мероприятия и дату.
4. Нажмите «Создать сертификаты».

PDF и ZIP сохраняются в папке приложения Documents/Certificates (внутренняя папка внешнего хранилища).

## Сборка
GitHub Actions workflow: Actions → Android APK. Артефакт после успешной сборки называется certificate-generator-debug-apk.
